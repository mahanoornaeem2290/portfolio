# Mahanoor's Portfolio 🚀

A modern, dynamic personal portfolio website for Mahanoor, an Aspiring Agentic AI Engineer & Front-End Developer.

## 🌟 Features

- **Responsive Design**: Looks great on desktop, tablet, and mobile.
- **Modern UI/UX**: Features glassmorphism, glowing effects, and smooth animations.
- **Interactive Elements**: Custom cursor and dynamic particle background.
- **Tech Stack**: Built purely with HTML5, CSS3, and Vanilla JavaScript.

## 🛠️ Technologies Used

- **HTML5**: Semantic structure.
- **CSS3**: Custom properties, flexbox/grid layouts, animations, and responsive media queries.
- **JavaScript (ES6+)**: DOM manipulation, interactive typing effects, and particle canvas rendering.
- **AOS (Animate On Scroll)**: For scroll animations.
- **Font Awesome**: For scalable vector icons.
- **Google Fonts**: Custom typography (Space Grotesk, Poppins, JetBrains Mono).

## 🚀 Getting Started

To view this project locally:

1. Clone this repository:
   ```bash
   git clone <your-repository-url>
   ```
2. Open the directory and launch `index.html` in your favorite web browser. No build steps or local server required!
